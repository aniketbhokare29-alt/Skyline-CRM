# Utils.java Explanation

File:

`src/main/java/com/saivandan/crm/Utils.java`

## Purpose

`Utils.java` contains reusable helper methods used by `App.java` and `Views.java`.

## Important helpers

- `readForm()` reads submitted HTML form data.
- `parsePairs()` converts form text into a map.
- `encode()` makes values safe for URLs.
- `decode()` converts URL values back to normal text.
- `escape()` protects HTML output from unsafe characters.
- `redirect()` sends the browser to another page.
- `sendHtml()` sends an HTML response.
- `sendCss()` sends the CSS file.
- `parseMoney()` converts money text into a number.

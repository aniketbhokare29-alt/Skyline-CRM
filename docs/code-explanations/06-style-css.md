# style.css Explanation

> Last updated: the stylesheet is unchanged but now lives at
> `frontend/css/style.css` and is referenced by every page in `frontend/`.

File:

`src/main/resources/static/style.css`

## Purpose

This file controls the appearance of the HTML pages generated by `Views.java`.

## Main sections

- CSS variables: colors, borders, and shadows.
- Body: global font and page background.
- Topbar: project name, role, and sign-out button.
- Sidebar: role navigation links.
- Cards: dashboard KPI cards.
- Tables: lists of CRM records.
- Forms: input fields and buttons.
- Status badges: Paid, Pending, Approved, and other statuses.
- Analytics: donut charts and legends.
- Responsive rules: mobile and tablet layouts.

Java creates the page structure. CSS controls how that structure looks.
